# 镜头职责表与远程对抗

一镜一职责。**四镜以上片段尽量覆盖不同职责，相邻镜头连续同职责需明确理由**——运镜是为职责服务的，不是为动而动。

## 一、镜头职责表（一镜一职责）

| 职责 | 内容 |
| --- | --- |
| 建立空间 | 人物出口障碍在哪：大全景/俯拍/侧向全身 |
| 追随位移 | 谁朝哪移速度怎变：平行/侧后/贴地跟拍 |
| 看清接触 | 是否命中接触点在哪：侧向中景/短促特写/动作匹配切 |
| 表达反制 | 主动权怎么变：反应近景/轴线同侧切入/回接双人景 |
| 表达失衡 | 受力方向姿态怎变：倾斜/短幅翻滚/沿受力方向追随 |
| 展示弹道 | 释放者路径目标关联：过肩/长焦压缩/高位距离景 |
| 揭示结果 | 谁获位置优势环境怎变：快速后拉/升镜/遮挡移开 |
| 稳定收尾 | 结果清楚后保留哪些运动：固定构图/稳定跟随/慢速轨道 |

- **四镜以上片段尽量覆盖不同职责，相邻镜头连续同职责需明确理由**
- **运镜在三维表达之上写全六要素**〔景别或焦段〕〔机位高度与角度〕〔运动速度〕〔摄影机方向〕〔跟随对象〕〔本镜职责〕
- **手持写成摄影师的物理操作行为**（呼吸、重心转移、肩扛重量、人为修正）避免数字抖动
- **摄影机指令写明绝不做什么**（他们离开时摄影机原地不动——不摇、不跟）

## 二、远程对抗与资源连续性

- 释放前交代武器、手部或能量来源
- 关键投射物可短暂追随，普通投射物优先直接切到落点
- 命中或落空后回到释放者交代换位、装填或资源变化
- 远程角色被贴身时用后撤、侧移、掩体或副武器反制
- **弹药、装填、充能状态与携带物、掉落物、伤势合并成统一的资源连续性追踪**

## 三、参考素材职责拆分

参考素材职责拆分（Ref2VA 与图生模式通用）：

- 首帧图锁定可见外观、正文重点写运动方向速度接触与后续状态
- 首尾帧写清起点到落点的动作因果、姿势机位空间自然衔接（过渡扭曲时缩小差异并增加中间落点）
- 动作参考视频只继承身体轨迹、节奏与发力方式
- 运镜参考视频只继承机位、摄影机路径与速度
- 分镜参考声明图片读取顺序并忽略分镜边框编号标注
- **一份素材不同时控制身份、场景、动作和镜头**

## 四、场景目标可见化闭环

- **动作场面的戏剧目标落成可见完成条件**（击倒/逼退/脱离/抵达/保护/拖延/撑到结束枚举里选），**结束画面必须兑现开头设定的完成条件**
- **对抗方改变目标达成条件而不是排队当靶子的规则保持**
