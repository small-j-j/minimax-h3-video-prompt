# 强化层：视场角语言块与光学纪律

镜头控制用「视场角度数+相机物理距离+可观察结果」替代镜头硬件参数。**写器材参数命中的是弱统计相关，写可观察结果跨模型稳定**。

## 一、视场角语言块

镜头控制用「视场角度数+相机物理距离+可观察结果」替代镜头硬件参数（不依赖毫米数、f 值、ISO、镜头品牌——写器材参数命中的是弱统计相关，写可观察结果跨模型稳定）；六档锚点：

| 档位 | 参数与用途 |
| --- | --- |
| 8° 超长焦 | 距 20–25 米，前景遮挡必备——模糊前景物占画面下部 30–45%，偷拍感与观察的疏离 |
| 18° 长焦 | 6–8 米，强背景压缩、刀锋级薄焦隔离眼睛、被远距离观察感 |
| 29° 短焦人像 | 4–6 米，人像默认档——特写靠镜头 reach 而非物理靠近、主体刀锋锐利背景化为奶油状柔焦 |
| 47° 标准 | 3–5 米，零明显畸变、自然比例、背景可读不夸张 |
| 84° 经典广角 | 1–1.5 米，强而自然的透视扩张、前景身体存在感更大更近、环境可见至画框边缘、直线平直无鱼眼 |
| 107° 超广角 | 0.5–0.8 米，慎用，大场景地理关系与极端沉浸 |

判档一句话算法：**把环境抽掉这一镜还成立吗——成立=故事在脸上（18–29°），不成立=故事在环境或关系里（84°，拿不准就选 84°，广角丢失的信息比长焦少）。**

## 二、内容-视场对齐律

- **同一节拍不混「面部肖像+环境地理+微距细节」三类内容（镜头漂移的头号原因），要混就用受控内切并给每镜独立镜头特性**
- **选定档位后从可观察结果词库堆叠——长焦至少 4 条、广角至少 3 条独立措辞**（单说一遍模型经常滑走）
- **防漂移锁**：模型反复把长焦画成中焦时加锁句「此镜头的任何部分都不得变成广角或标准镜头覆盖，更宽的取景只能通过摄影机离得更远实现，不换更短的镜头」

## 三、光学反模式禁止

- extreme wide-angle 无量词
- 把 wide shot/establishing shot 当镜头指令（那是景别）
- zoom out 与 wide-angle 并存
- 纯器材参数控制
- 摄影师名字串烧
- 纯否定镜头控制（不要广角没告诉模型要什么）

## 四、弱词替换与朝向视线分离

- **禁「靠近/周围/旁边/某处/附近」类弱词，替换为可测量表述**（1 米以内/接触/靴子位于树根圈内/背靠墙壁/右手四指扣住杯身）
  - 反例→正例：『他站在门附近』→『他的靴子踩在门槛内侧，背靠门框』；『手放在桌上』→『右手四指扣住杯身，拇指压住杯沿』
- **身体朝向与视线分开写**（躯干朝向画面右侧、头微转、视线锁定画面左侧的人——模型会混为一谈给出呆板侧身）
  - 反例→正例：『他侧身看着她』（朝向与视线糊在一起）→『躯干朝画右，头微转向画左，视线锁定画左站着的人』
- **地标邻近性物理锚定**（直接站在标牌下方、手可以碰到）
