# 说话人、对白与画面文字

说话人 ID 与对白标签是 H3 的格式契约重灾区。**逐字保留、不翻译不改写**——`<d>` 内只放语言标签与用户提供的对白/歌词原文。

## 一、说话人与对白

- 说话、唱歌或发出画外人声的主体给全局稳定 ID **(S1)(S2)**，多个已编号说话人同时说话用复合 ID **(S1,S2)**，**同一说话人跨镜头保持同一 ID，从不发声的角色不给 ID**
- **首次出现时用视觉与声音上下文建立稳定身份**（角色类型、年龄、性别、是否出画、音高、音色、语速、口音）
- **身份短语、ID、动作、交付方式写在 `<d>` 标签外，`<d>` 内只放语言标签与用户提供的对白/歌词原文**（如 'The young woman with a quiet, breathy voice (S1) says: <d>[English] I get off at the next station.</d>'），**逐字保留、不翻译不改写**
- **旁白用固定短语 'says in an off-screen voiceover'**，且其 `<d>` 块后紧跟说明对应画内角色双唇紧闭（'while his lips remain completely closed'）
- **同一句对白或歌词跨越剪辑点时在两侧衔接处用 `<scenetrans>` 并明说声音延续**（'continues seamlessly across the cut' 家族表达）
- **视频结束截断语音用 `<cutoff>`**

## 二、画面文字

屏幕内实际可见的字幕、招牌、标签、霓虹文字用**英文双引号包裹并原样保留原文与标点、不翻译**（如 'A red neon sign reading 「营业中」 glows above the doorway.'，成稿中「」处换成英文双引号包裹原文）。

## 三、审查

- [ ] 说话人全局稳定 ID：(S1)(S2) 按实际发声事件分配一次全程复用，从不发声的角色未给 ID
- [ ] 复合 ID (S1,S2) 仅用于多个已编号说话人同时说话
- [ ] 首次出现已用视觉与声音上下文建立稳定身份
- [ ] `<d>` 内只放语言标签+对白/歌词原文，逐字未翻译未改写
- [ ] 旁白固定短语 + `<d>` 后紧跟画内角色双唇紧闭说明
- [ ] 跨剪辑点延续的声音用 `<scenetrans>` 明说延续；结束截断用 `<cutoff>`
- [ ] 画面可见文字用英文双引号包裹原文与标点，未翻译
