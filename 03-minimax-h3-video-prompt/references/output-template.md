# 输出模板

交付时严格按本模板输出。**每一次交付回复都按四段骨架组织**（结论/成品/依据/下一步）；成品为代码块整体包裹的完整 H3 提示词。

## 一、四段骨架

| 段 | 内容 | 要求 |
|----|------|------|
| 结论 | 模式判定（T2VA/I2VA/FL2VA/L2VA/Ref2VA）+ 时长与镜头规划一句话 | 多关系模式时给出路由理由 |
| 成品 | 可直接粘贴进生成端的完整 H3 提示词 | **代码块整体包裹**：基础模式=首行对齐指令（T2VA 无对齐指令直接进三字段）+ 空行 + integrated_multimodal_description / overall_soundscape / non_diegetic_music 三字段；Ref2VA=六段结构，字段名、段落顺序、标签拼写逐字保留 |
| 依据 | 自检 ✅/❌/⚠️ 逐条 | 指令首行与两位小数时长 / 时间戳严格递增 / 说话人 ID 全局稳定 / 对白与画面文字逐字 / 两个声音字段分工 / 标签无未解析 / 总时长匹配 / 视场角档位与内容-视场对齐 / 一镜一职责 / 末尾【强制声明】 |
| 下一步 | 生成参数建议与可调方向 | 时长 4–15 秒、分辨率、画幅；对白、运镜、音乐、镜头密度 |

禁止输出「已按技能执行/内部规则」类流程自评，禁止暴露规则编号。

## 二、成品组织

完整 H3 提示词按模式组织，代码块整体包裹：

| 模式 | 组织顺序 |
|------|----------|
| T2VA | 无首行对齐指令，直接三字段：integrated_multimodal_description → overall_soundscape → non_diegetic_music |
| I2VA | 首行对齐指令（固定句）→ 空行 → 三字段 |
| FL2VA | 首行对齐指令（固定句）→ 空行 → 三字段 |
| L2VA | 首行对齐指令（固定句）→ 空行 → 三字段 |
| Ref2VA | 六段顺序固定全英文：subject_definitions → summary → retention_analysis → detailed_description → overall_soundscape → non_diegetic_music |

**成品末尾硬约束**：视频提示词全文末尾原样附上——禁止项: 文字/UI/水印/Logo/角标/可读文字/真实UI。【强制声明】无背景音乐，仅保留环境音与人声；画面禁字幕/文字/水印/Logo；禁止可读文字；禁止超现实夸张；禁止无反作用力动作。

逐字骨架与填空位置见 `corpus.md`。

## 三、产出示例

```text
「你要的『雨夜车站告别，8 秒，男主有一句中文台词』给了首尾两张图，判定 FL2VA 模式单镜头：首行对齐指令把 Picture 1 锁在 0.00 秒、Picture 2 锁在 8.00 秒（两位小数）；description 不重复两张图的静态描述，只写连接它们的连续路径——低头看信 → 抬伞 → 转身时伞面水珠滑落；男主 (S1) 的台词在 <d>[Chinese] 里逐字保留你的原文；overall_soundscape 只收雨声、织物摩擦与车站环境音，non_diegetic_music 写大提琴与钢琴的乐器配置和力度变化、不带情绪词。」
```

## 四、交付前检查

- [ ] 四段齐全：结论（模式判定+时长镜头规划）/ 成品（代码块整体包裹）/ 依据（自检 ✅/❌/⚠️ 逐条）/ 下一步（生成参数建议+可调方向）
- [ ] 字段名与段落顺序逐字一致；对齐指令在第一行且 S.SS 精确到两位小数（T2VA 跳过）
- [ ] 说话人 ID 全局稳定；`<d>` 内对白歌词逐字未翻译；画面文字英文双引号包裹
- [ ] 两个声音字段分工正确；Ref2VA 标签全程同义无未解析项
- [ ] 描述总时长与请求时长（4–15 秒）匹配
- [ ] 提示词全文末尾已原样附上【强制声明】，逐字未改
- [ ] 未输出流程自评、未暴露规则编号
